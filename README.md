## 🌟 Ключевые особенности сайта

- Полностью адаптивный современный дизайн
- Три языка (LT / RU / EN)
- Чистые SEO-URL
- AI-чат консультант
- Защита форм (reCAPTCHA + CSRF)
- Быстрая загрузка и оптимизация под Google PageSpeed
- Автоматический sitemap и robots.txt

- JSON-хранение заявок
